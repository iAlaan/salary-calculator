คำนวณแม่นยำ รองรับรายวัน รายเดือน นำเข้าและส่งออก Excel ได้ง่ายดาย

สูตรการคำนวณ OT ตามเงื่อนไข:

อัตราต่อชั่วโมง = (ฐานเงินเดือนหรือเทียบเท่า) ÷ 30 ÷ 8

ค่า OT = อัตราต่อชั่วโมง × จำนวนชั่วโมง OT × ตัวคูณ (1.5, 2, 3)

ยอดเงินสุทธิที่ต้องจ่าย
0.00 บาท

นำเข้าข้อมูลพนักงานจากไฟล์ Excel หรือ CSV

อัปโหลดไฟล์ที่มีรายชื่อและข้อมูลการทำงานเพื่อประมวลผลเงินเดือนพร้อมกัน

คลิกเพื่อเลือกไฟล์ หรือลากไฟล์มาวางที่นี่

รองรับไฟล์ฟอร์แมต .xlsx, .xls หรือ .csv

รูปแบบคอลัมน์ในไฟล์ Excel ที่รองรับ:
name : ชื่อพนักงาน
type : monthly / daily
salary_or_daily : เงินเดือน/ค่าจ้างรายวัน
work_days : วันที่ทำงาน
ot15 : ชม. OT 1.5
ot20 : ชม. OT 2.0
ot30 : ชม. OT 3.0
other_income / deductions

ผลการประมวลผลเงินเดือนพนักงานทั้งบริษัท

พบพนักงานทั้งหมด 0 คน ยอดจ่ายสุทธิรวม 0.00 บาท

ลำดับ ชื่อ-นามสกุล ประเภท ฐานเงินเดือน/วัน วันทำงาน ค่าจ้างงวดงาน ค่า OT รวม รายได้อื่นๆ หักอื่นๆ สุทธิ
